# 復興檔案：時光的邀請

臺北市私立復興實驗高級中學校園探索解謎互動 Web App，題目與敘事特別為 7–9 年級（國中）學生設計。八道任務已改為**困難模式**：每關一種獨立推理機制，建議 60 分鐘完成，完整規格見 [`HARD_MODE_DESIGN.md`](./HARD_MODE_DESIGN.md)。保留校園故事、互動 SVG 示意地圖、記憶碎片、校史館休館替代情節與最終謎題。故事敘事文字採手寫風格字體（霞鶩文楷 LXGW WenKai TC，透過 Google Fonts 載入，離線時自動降級為系統楷體）。

遊戲支援三種遊玩模式：

| 模式 | 說明 | 需要網路 | 需要帳號 |
|------|------|----------|----------|
| 離線單機 | 進度存於瀏覽器 Local Storage，可完全離線遊玩 | 否 | 否 |
| 雲端存檔 | 登入後進度同步至 Supabase，換手機／換電腦都能繼續 | 首次與同步時需要 | 是（免 email 驗證） |
| 組隊遊玩 | 建立／加入隊伍（6 碼代碼），全隊共解八道任務，即時同步進度、隊員分工紀錄與團隊排行榜 | 需要 | 是（免 email 驗證） |

## 困難模式八關

| 關卡 | 名稱 | 互動機制 | 建議時間 |
|---|---|---|---:|
| M01 | 不在場的證詞 | 三欄證據分類（可證實／矛盾／未載）＋校驗字 | 7 分 |
| M02 | 鐘樓的四行密令 | 四個語意槽位選詩，讀出藏頭密令 | 6 分 |
| M03 | 六座空間的身分危機 | 6×6 邏輯矩陣＋六組配對 | 8 分 |
| M04 | 被竄改的時間軸 | 事件排序＋民國／西元換算 | 8 分 |
| M05 | 徽章上的雙重密碼 | 六組配對＋索引字密文 | 7 分 |
| M06 | 綠色循環的缺頁 | 概念循環排序＋三題短答（概念條件評分） | 7 分 |
| M07 | 八份求助紀錄 | 四處室各兩件的受限配額分派 | 8 分 |
| M08 | 時光回信：最後的校驗 | 跨關交叉校驗＋終章口令 | 9 分 |

- **限時**：60 分鐘倒數（`TIME_LIMIT_SECONDS`）。時間到只會在畫面上標示超時、成績單註記「已超時」，仍可繼續作答與查看解答；剩 5 分鐘時倒數轉為琥珀色。
- **提示**：每關三階提示（觀察方向 → 推理策略 → 關鍵關係），每開一階該關 −1 分，每關最多 −3 分；未完成關卡的提示不扣分。
- **評分**：八關各 10 分、終章 10 分、八關全破且完成終章再加 10 分，滿分 100 分（扣除提示）。
- **回饋**：錯誤提交只說明「還有幾項／幾組要修正」，不顯示正解；正解在通關後與教師解答本中呈現。
- **短答評分**：M06 的追問採「必要概念組 + 禁用詞」比對，不是模糊包含比對；其餘答案皆經正規化（全形／半形、空白、標點）。

## 啟動

```bash
npm install
npm run dev
```

開啟 `http://localhost:3000`。離線模式無需任何設定；雲端與組隊模式使用內建的 Supabase 專案設定（見下節）。

## 雲端與組隊（Supabase）

雲端與組隊功能透過 Supabase（Auth + Postgres + Realtime）運作，純前端呼叫、不需要自建伺服器：

- **帳號**：電子郵件＋密碼註冊即自動確認（此專案已關閉 email 驗證信，方便校園活動快速開帳號）。密碼至少 6 碼。
- **跨裝置存檔**：登入後遊玩進度寫入 `solo_saves` 資料表；換裝置登入即可繼續。
- **組隊遊玩**：`create_team` / `join_team_by_code` RPC 建立或加入隊伍；`team_sessions` 共享全隊進度，`team_mission_log` 記錄「誰解開哪一關」；Supabase Realtime 即時把隊友的進度推到每個人的畫面。
- **排行榜**：`team_leaderboard` RPC 依分數、完成時間排序全隊伍。

資料表皆啟用 Row Level Security：每個人只能讀寫自己的存檔與所屬隊伍的資料；加入隊伍必須透過代碼（6 碼，排除 0/O/1/I/L 等易混淆字元）。

要連到自己的 Supabase 專案時，設定環境變數即可覆寫預設值：

```bash
NEXT_PUBLIC_SUPABASE_URL=https://your-project.supabase.co
NEXT_PUBLIC_SUPABASE_ANON_KEY=your-anon-key
```

> anon key 本來就會隨靜態網站送到瀏覽器（安全邊界是 RLS，不是這把 key），請勿在前端放 service role key。

## 靜態建置

```bash
npm run build
```

Next.js 靜態匯出會產生 `out/`，可部署到任意靜態網站主機（含 Vercel）。離線模式搭配 Service Worker 快取可離線開啟；雲端／組隊模式需要網路連線，斷線時進度會保留於記憶體並於恢復連線後自動補上同步。

## 紙本印刷品（混合手冊）

`public/printables/` 內含可直接列印的 PDF（A5 直式），採「**紙本線索・系統作答**」分工：

- **紙本＝唯一線索來源**：每關一頁線索卡（證詞卡、殘詩、事件卡、意涵卡、概念卡、求助紀錄、校驗欄），題目資料只印在紙上。
- **網站＝作答系統**：任務頁只顯示「本關線索在紙本：線索卡 M0x」、該卡提供哪些資料的清單、以及與紙本欄位代號完全相同的作答表（空間卡 A、任務卡 ①、事件卡 A…），送出後才由 `gradeMissionAnswer` 判分。

網站不再重現題目資料，因此**沒印手冊就無法解題**——這是刻意的設計，讓紙本不能被網站取代。欄位定義集中在 `src/lib/answer-sheets.ts`，同一份資料同時驅動網站作答介面（`AnswerSheet.tsx`）與學生手冊的作答欄，兩邊不會說法不一致。

因為檔案放在 `public/` 底下，靜態網站會直接提供這些 PDF；遊戲內的「列印素材與安全」視窗、任務頁與過關彈窗的資料連結全部指向這裡，不再連向外站網址。

| 檔案 | 站內網址 | 用途 |
|------|------|------|
| `復興探索手冊_學生版.pdf` | `/printables/復興探索手冊_學生版.pdf` | 學生線索卡手冊：玩法、校園地圖、八張線索卡（線索＋作答欄）＋現場觀察欄、碎片收集頁、終章排列題、作答進度表 |
| `復興探索手冊_教師解答本.pdf` | `/printables/復興探索手冊_教師解答本.pdf` | 教師用：逐關解答、觀察題參考答案、解題提示、評分與安全建議 |
| `campus-map.png` | `/printables/campus-map.png` | 印刷地圖（300dpi，含任務編號針腳） |

重新產生（輸出到 `public/printables/`）：

```bash
python3 scripts/render-map.py               # 由 CampusMapSVG.tsx 重繪印刷地圖
npx tsx scripts/generate-booklets.ts        # 依題庫（src/lib/seed-data.ts）產出兩本 PDF
```

字體使用霞鶩文楷（`@expo-google-fonts/lxgw-wenkai-tc`，與遊戲介面手寫字體一致），PDF 產生器使用 `pdfkit`；兩者皆已列入 `devDependencies`，執行 `npm install` 即可重新產生手冊。

## 備註

- 離線模式進度只寫入同一瀏覽器的 Local Storage，清除瀏覽器網站資料會刪除進度；建議長時間遊玩改用雲端存檔模式。
- 雲端／組隊模式沒有伺服器端防作弊驗證，適合課堂與活動使用，不適用於嚴肅競賽。
- 困難模式的答案、校驗字與提示同樣隨靜態前端送到瀏覽器（離線模式為本地驗證）；介面與文件皆未宣稱答案受到保護，若要防止檢視原始碼取得答案，需改為伺服器端驗證。
- 校園地圖是示意圖，並非精確建築平面圖或 GPS 圖資；關卡位置不可視為已核實的實際座標。
- 關卡題目皆可純文字作答，不以照片或校徽圖像作為解題必要條件；首頁校園照片與序章主視覺僅作為裝飾素材（序章圖為 AI 生成之示意圖，非復興實中實景），出處與聲明見 `public/images/IMAGE_SOURCES.md`。
- 題庫正確答案會隨靜態遊戲程式送至瀏覽器，因此本遊戲適合個人與班級遊玩。
