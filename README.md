# 復興檔案：時光的邀請

臺北市私立復興實驗高級中學校園探索解謎互動 Web App。保留八道任務、校園故事、互動 SVG 示意地圖、記憶碎片、校史館休館替代情節與最終謎題。遊戲以單人、單一瀏覽器本機存檔方式執行，不需要帳號、API 伺服器或資料庫。

## 啟動

```bash
npm install
npm run dev
```

開啟 `http://localhost:3000`。無需 `.env`、PostgreSQL 或資料庫遷移。

## 靜態單機建置

```bash
npm run build
```

Next.js 靜態匯出會產生 `out/`，可部署到任意靜態網站主機，也可複製到校內網站。首次載入後，Service Worker 會快取應用程式資產，之後可在同一瀏覽器離線開啟。所有題庫與謎題規則在瀏覽器本機執行；存檔只寫入同一瀏覽器的 Local Storage，不會跨裝置同步。清除瀏覽器網站資料會刪除進度。

可用 Python 在本機預覽匯出檔案：

```bash
python3 -m http.server 4173 --directory out
```

## 驗證

```bash
npm test
npm run typecheck
npm run lint
npm run build
```

## 備註

- 此版本為單人單機體驗；不含帳號、雲端存檔、多人隊伍、管理員後台、API 或資料庫。
- 校園地圖是示意圖，並非精確建築平面圖或 GPS 圖資；關卡位置不可視為已核實的實際座標。
- 校園實景圖片尚待校方提供；缺少時會顯示清楚標記為非實景的佔位圖。
- 題庫正確答案會隨靜態遊戲程式送至瀏覽器，因此本模式適合個人遊玩，不提供伺服器端防作弊驗證。
